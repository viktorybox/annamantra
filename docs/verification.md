# Проверка 26 октября 2026

Проверена production-сборка Astro 7.4.2 в Chromium.

## Автоматические проверки

- `npm run check`: без ошибок, предупреждений и подсказок.
- `npm run build`: успешная статическая сборка.
- `npm run check:site`: проверены 12 HTML-страниц — внутренние ссылки, якоря, ресурсы, язык, заголовки и связи `aria-controls`.
- `npm run check --prefix studio`: схемы и конфигурация админки проходят TypeScript.
- Локальная сборка Studio проходит с временным идентификатором для проверки конфигурации. Настоящий проект и вход владельца ещё не подключены.
- Аудит зависимостей сайта и Studio: 0 известных уязвимостей после обновлений.
- `git diff --check`: ошибок пробелов нет.

## Браузерные сценарии

- Замедленная сеть: индикатор виден до и после запуска скрипта; в покадровой выборке нет пустых кадров или наложения запасной и основной иконок.
- «Практики → Главная» и активное «Ещё → Главная»: плавное движение влево, прокрутка завершается наверху. Переход из «Практик» дополнительно повторён три раза.
- Круг сохраняется при смене страницы. Между его нижней границей и подписью остаётся 4 px; непрозрачной прямоугольной подложки нет.
- «Ещё»: открытие, закрытие Esc, переход к FAQ на главной и из блога, состояние `aria-expanded`.
- Кнопки браузера «Назад» и «Вперёд», сохранение DOM-элемента меню.
- Обновление активного пункта при прокрутке к «Об Анне» и «Практикам».
- FAQ: 9 вопросов в каждой языковой версии, раскрытие ответа.
- RU и FR на ширинах 320, 360, 390, 430, 768 и 1440 px: без горизонтальной прокрутки; основной текст 20 px; подписи меню остаются внутри экрана.
- Мобильная эмуляция 390 px и прокрутка touch-жестом: работают, ширина содержимого равна ширине экрана.
- Переключение RU → FR, белый неактивный язык, переход из французской навигации в русский квиз.
- Квиз: восстановление после перезагрузки, возврат и изменение ответа, все 7 вопросов, результат при ничьей, загрузка изображения, повторный вход через меню.
- `prefers-reduced-motion`: переход к началу страницы и мгновенное состояние индикатора.
- Якорь первого экрана, возврат по логотипу, адрес с query-параметрами и фокус клавиатурной ссылки «К содержанию».
- В проверенных сценариях: 0 исключений JavaScript и 0 ошибок загрузки локальных ресурсов.
